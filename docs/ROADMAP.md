# 路线图

## 已完成

### v0.15.0

- PAT 号池方案 A：号池总览、已验证可用统计、折叠账号卡片、需关注筛选。
- 显式凭据保存与逐账号验证；保存状态和验证状态分开。
- 冷却原因与预计恢复时间展示。
- 按会话记录实际请求账号，自动换号跟随真实请求，多个会话互不污染。
- 对话栏额度徽标跟随实际账号；同一席位换 PAT 后历史归属不被重写。

### v0.14.5

- 记录 Trae 企业端点与指定模型的图片探测观测及证据边界。
- 将绝对化的“上游只接受 user 图片”表述改为有日期、模型范围和局限的兼容策略说明。

### v0.14.4

- 修复多模态图片从未真正发送的缺陷：附件读取 target 字段名不符合宿主契约，异常被吞掉后静默降级为 `[image omitted]`。

### v0.14.3

- 账号配对警告、命名空间一致性自检、多席位额度并发查询。

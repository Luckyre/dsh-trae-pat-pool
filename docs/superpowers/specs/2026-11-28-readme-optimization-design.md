## 1. 目标

### 3.3 “它解决什么问题”

用 4 个短条目替代现有 11 条密集特性列表：

### 3.4 “界面怎么看”

用编号列表对应主图：

1. 号池概览：账号总数、已配置、已验证可用、冷却/异常、待配置/待验证是不同维度，不相加。
2. 账号卡片：优先级、PAT 身份、验证状态、冷却原因与额度来源；卡片默认折叠凭据。
3. 当前会话账号：使用中、上次使用、尚未使用、自动换号原因；多个会话各自记录。
4. 对话栏额度：按实际账号读取；额度未知时保留账号标识，不用主席位数字猜测。

### 3.5 “三步上手”

第一章：安装。

- Release 下载 `dsh-trae-pat-pool-0.15.0.tgz`。
- 命令：`dsh plugin --profile desktop add ./dsh-trae-pat-pool-0.15.0.tgz`。
- 或在 DSH 侧栏“插件 → 添加插件”选择安装包。
- 安装完成后重启 DSH。

第二章：添加 PAT。

- 设置 → 左侧 Trae 号池 → 添加账号。
- 填 PAT → 点击“保存并验证”。
- 企业版如需查额度，再展开账号填写控制台邮箱与密码。

第三章：使用模型。

- 新建或打开对话，模型菜单选择 Trae 分组。
- 发送消息后，对话栏显示本次使用的账号。
- 额度徽标在该账号额度可用时显示。

命令块只保留安装与卸载命令，不放配置 YAML。

# 已知限制

## 图片

- 当前只转发用户消息中的图片：直接贴图可走视觉链路。
- 工具轮次结果中的图片（如 `read_image` / 截图）仍被替换为 `[image omitted]`；OCR 识别出的文字仍可传递。
- 单图长边上限 1024px、单图 2MB；超出会由 DSH 重新编码，超大图可能细节不可辨。
- 2026-11-27 的探测只覆盖 Trae 企业端点与 `DeepSeek-V4.1-Flash-1017__max`，且提示与刺激存在不匹配、部分回读答案为空等局限。HTTP 200 不等于视觉理解，单次阴性结果不能证明所有模型永久忽略工具图片。

详见 [图片观测记录](tool-image-observation-2026-11-27.md)。

## 企业版额度

- 额度记在控制台账号上，不认 PAT。两个席位共用同一控制台账号会读到同一份数字。
- PAT 账号与控制台邮箱不一致时会提示，但不拦截；子账号或代管场景可能合法不同。
- SSO-only 租户不能使用控制台额度路径；个人版额度走 IDE 接口，无需控制台账号。

## 上游协议

Trae 接口为未公开内部接口，上游改协议可能导致插件失效。模型目录会在启动、换 PAT 和手动刷新时询问真实目录，并保留缓存/内置表作为断网降级。
